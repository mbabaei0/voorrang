## Destination

A build-ready spec for a free, static (no backend), mobile-friendly web app where Dutch learner drivers solve 3D "who goes first?" puzzles under Dutch priority rules (voorrangsregels), in Dutch and English. Done when content model, curriculum, interaction, and stack are decided and someone could start building without further decisions.

## Notes

- Domain: Dutch traffic law (RVV 1990) as tested by the CBR theory exam. Audience: learner drivers.
- Glossary: [CONTEXT.md](../CONTEXT.md). Use its terms (Scenario, Road user, Passing order, Puzzle, Replay).
- Standing preferences: 3D with three.js; framework open. Core interaction = tap road users in passing order, then watch the replay. Simultaneous moves allowed; deadlocks as an optional advanced type. Progress in browser storage only.
- Topics in scope: unmarked junctions (incl. bikes/mopeds from the right), priority signs and haaientanden, traffic lights (incl. out-of-order), roundabouts, turning conflicts, emergency vehicles, trams, uitritten, erven.
- Skills: grilling + domain-modeling for grilling tickets; prototype for prototype tickets; research for research tickets.
- Planning only: produce decisions, not the app.

## Decisions so far

<!-- one line per closed ticket -->
- [Research: Dutch priority rules as tested by CBR](0001-research-dutch-priority-rules.md): RVV 84>64>63 hierarchy plus arts. 15/18/49/50/54/80 fully cover the in-scope topics; the CBR sleepvraag (number road users 1-2-3) is the native passing-order format; deadlocks have no legal tie-break (resolved by waiver).
- [Research: three.js stack and asset options](0002-research-threejs-stack-and-assets.md): All three.js wrappers viable (gz JS: vanilla ~155 KB, Threlte ~230, Tres ~266, R3F v9 ~320; R3F v10 alpha is a breaking change); CC0 road users from Kenney/Quaternius, public-domain RVV sign SVGs from Commons, roads best generated procedurally; target ≤100 draw calls, render-on-demand.
- [Research: CBR answer conventions for ties, pedestrians and roundabout cyclists](0007-research-cbr-ties-and-pedestrians.md): CBR sleepvraag order is strict (one token per number, so ties are an app-only extension); turning drivers must let straight-on pedestrians on the same road go (art. 18 "voor laten gaan", not voorrang); roundabout cyclist priority is never law, only signs/haaientanden decide (CROW binnen/buiten bebouwde kom is non-binding).
- [Grilling: the scenario model](0003-grilling-scenario-model.md): authored Passing orders checked by a build-time rules engine (overrides only via cited CBR conventions); ~4 parametrised Layouts with Controls on Arms; road users = kind + arm + Manoeuvre + lane, optional "You"; order = Steps (sets, any order within a Step); deadlocks via waiver Step + engine-derived rest; per-road-user Explanations from Rule templates; rotated Variants, never mirrored.
- [Grilling: curriculum shape](0004-grilling-curriculum-shape.md): 10 unlocked Topics in suggested order (unmarked junctions first, Mixed + Deadlocks last); Lesson / Practice / Exam (10 puzzles, 9 to pass, feedback at end); explanation after every Replay; difficulty derived from road-user and Rule count; mastery = 5 first-try correct in a row on distinct scenarios; ≥12 scenarios per topic at launch. (Agent-decided, delegated by user.)
- [Grilling: framework and build stack](0005-grilling-framework-and-build-stack.md): TypeScript + SvelteKit (adapter-static, /nl and /en routes) shell around a vanilla three.js scene module; Paraglide i18n; Svelte 5 runes + versioned localStorage; one JSON file per Scenario, Zod schema + rules engine checked in Vitest at build. (Agent-decided, delegated by user.)

## Not yet specified

- Visual style / art direction. Stack research leans "low-poly, toy-like, flat colours" (fits CC0 Kenney/Quaternius and mobile budgets). Open sub-points: no CC0 tram found (CC-BY, custom, or procedural box), and a licence manifest + credits page if any CC-BY asset is used.
- Who writes and reviews the Dutch (and English) content. Library chosen (Paraglide); authorship and review are not. Note: CBR keeps "erf" and some terms in Dutch in English exams.
- Accessibility: colour-blind-safe signals, non-3D fallback, keyboard/screen-reader paths.
- Hosting and deployment of the static site.
- Content freeze check: adopted RVV amendments with no start date yet; re-check the change list before content is finalised.

## Out of scope

- Police hand signals (later effort). Caveat from rules research: the CBR exam does test RVV Bijlage 2 gestures, so leaving them out costs exam coverage. Confirm with the user.
- Countries other than the Netherlands.
- Accounts, backend, sync.
- Free-drive simulation mode.
